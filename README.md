# PaceTrace

A campus run management dashboard.

## Quick Start

```bash
pip install -r requirements.txt
python run_ui.py
```

Open `http://localhost:8501` in your browser.

## Configuration

Set your AMap API key in `.env` for better map accuracy:

```
AMAP_KEY=your_amap_js_api_key
```
